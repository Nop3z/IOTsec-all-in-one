# GA100 数据中心 GPU PWMVID 电压毛刺实验台

> 来源：kate-land (GitHub, MIT) · 2026-11-14 · [原文](https://github.com/kate-land/ga100vfi)
> 归档用于安全研究参考；版权归原作者所有。

## 收录理由

- **核心**：注入点＝GPU 的 PWMVID 供电控制路径（不直接短接电源轨，而是对 PWM 波形加窗/变形，经 loopback HTTP API 由 ARM 驱动下发）；触发＝波形序列本身（arm/sequence/stop）；判定＝两次有界 CMD_READ 的状态对账出现目标“已发布安全别名”表型，即停止循环交独立复核。
- **价值**：把电压毛刺从 MCU 推到数据中心 GPU 的供电管理接口，方法学（一次性尝试 + 证据链 + 拒绝重放）值得迁移到任何“打坏了很贵”的目标。
- **难度**：极高 —— 需要自制 PWMVID 板、GPU 实验卡与严格的实验纪律，成本与风险都很高。

自研 PWMVID 控制板（STM32G431）生成可控 PWM 波形驱动 NVIDIA GA100 的 PWMVID 供电接口，配合“一次性尝试 + 只读基线 + 证据分类”的 glitch-loop 纪律，并用 GPU0 只读寄存器捕获（BAR0/BAR1 两次 512 行 CMD_READ）观察毛刺后的安全别名/fuse 状态变化。

## 方法论启示

- 对昂贵目标，“一次性尝试 + 只读基线 + 拒绝重放”的实验纪律比扫参技巧更重要。
- 打供电管理接口（PWMVID 波形）而不是直接短接电源轨，是数据中心设备的可行注入面。
