# 打印机攻击面与 PJL 后门：用打印语言控制设备

> 来源：Context Information Security · 2017-06-01 · [原文](https://www.contextis.com/en/blog/printer-exploitation)
> 归档用于安全研究参考；版权归原作者所有。

## 收录理由

- **核心**：打印语言本质上是运行在设备上的脚本环境；PJL 的文件系统访问和 Web 管理面组合，能构成完整的持久化链。
- **价值**：打印机是最被低估的内网设备之一：它常驻内网、带存储、有 Web 面与“可编程语言”，却极少被纳入安全基线。
- **难度**：中 —— 需要理解 PJL/PostScript 与厂商 Web 接口。

对办公打印机的攻击面做系统梳理：PJL/PS 等打印语言可被用来读写文件、执行命令，甚至写持久化脚本；打印机常被当作“哑设备”而缺乏监控。
