# Lessons from Building an Open-Architecture Secure Element（39C3）

> 来源：39C3 · 2025-12-28 · [原文](https://media.ccc.de/v/39c3-lessons-from-building-an-open-architecture-secure-element)

## 收录理由

- **核心**：开源 SE 的难点不只在芯片设计，还在可验证构建、第三方 IP 与合规边界。
- **价值**：硬件钱包信任根走向开源的关键工程记录。
- **难度**：中 —— 工程/流程型分享。

从零构建开源架构安全元件的经验：为什么把“开放”纳入安全模型、它如何改变设计与开发流程，以及法律、第三方 IP 与出口管制带来的现实约束。
